
# MADAM Lite

Run Localy on Frontend side.

## Langkah-langkah untuk Menjalankan Aplikasi

### 1. Clone Proyek

Clone repositori MADAM Lite dari GitHub:

```bash
git clone https://github.com/kodegiri/MADAM-lite-FE.git
```

### 2. Masuk ke Direktori Proyek

Pindah ke direktori proyek MADAM Lite yang telah di-clone:

```bash
cd MADAM-lite-FE
```

### 3. Instalasi Dependensi

Install semua paket dan dependensi yang diperlukan menggunakan npm:

```bash
npm install
```

### 4. Memulai Server

Jalankan server pengembangan lokal untuk proyek MADAM Lite:

```bash
npm run dev
```
