
# MADAM Lite



## Run Locally

Clone the project

```bash
  git clone https://github.com/kodegiri/MADAM-lite-BE.git
```

Go to the project directory

```bash
  cd MADAM-lite-BE
```

Setting env
```bash
  rename .env.example to .env
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start
```

Any content will be served at ```http://localhost:3000/```
